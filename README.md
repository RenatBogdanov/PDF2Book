# Конвертер PDF в Брошюру 

Простой скрипт для преобразования PDF в формат брошюры.

## Описание
Этот скрипт переставляет страницы PDF-документа в порядке, подходящем для печати в виде брошюры. Поддерживает чётное и нечётное количество страниц, автоматически корректируя порядок для правильного складывания.

## Установка
Убедитесь, что установлен Python и библиотека PyPDF2:
```bash
pip install PyPDF2
```

## Использование
```bash
python pdf2book.py input.pdf output.pdf
```
- `input.pdf` — путь к исходному PDF-файлу.
- `output.pdf` — путь для сохранения преобразованного файла.

## Пример
```bash
python pdf2book.py example.pdf brochure.pdf
```

## Особенности
- Автоматически корректирует порядок страниц для печати брошюры.
- Если количество страниц нечётное, последняя страница добавляется в конец.
- Учитывает особенности складывания листов (меняет местами каждую 3 и 4 страницу в группах по 4).

## Ограничения
- Входной PDF не должен быть защищён паролем.
- Рекомендуется использовать для документов с чётным количеством страниц.
